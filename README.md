# WildDiscover

WildDiscover is an AI-powered predictive mapping platform that helps citizen scientists identify potential habitats for climate-displaced and rare Australian bird species. It combines historical sightings with current environmental and terrain data to reveal possible “ghost habitats” while keeping vulnerable species’ exact locations protected.

## The problem

Climate change is shifting bird populations beyond their historically recorded ranges. Birdwatchers need clearer guidance on where to search for rare or seemingly lost species, along with a safe way to report sightings without exposing sensitive locations.

## What WildDiscover does

- Predicts potential habitats for rare and climate-displaced birds.
- Supports birdwatchers with location-aware search guidance.
- Encourages citizen-science contributions through sighting reports.
- Protects vulnerable species by keeping precise sighting locations private.
- Supports birdwatchers with location-aware search guidance and overlays of popular viewing points.
- Encourages citizen-science contributions through sighting reports and an Investigation Journal.
- Gamifies conservation education with an interactive Bird Call Challenge and Global Leaderboard.
- Protects vulnerable species by algorithmically blurring precise sighting locations to keep them private.
- Maintains strict academic credibility by sourcing data from CSIRO, the Atlas of Living Australia (ALA), and the EPBC Act Database.

## Target users

WildDiscover is designed for birdwatchers and citizen scientists who want to discover, document, and help protect Australia’s rare and displaced bird species.

## Example: the Night Parrot

The platform explores how species such as Australia’s Night Parrot—once believed extinct for more than a century—may persist in changing or previously overlooked habitats.

## Continuous Deployment & Versioning

The application is automatically built and distributed via a GitHub-connected Continuous Deployment (CI/CD) pipeline, completely eliminating manual server uploads.

* **Frontend Hosting (Vercel)**: The Vue.js interface automatically builds upon pushes to `main`.
* **Unified Hosting Strategy**: The backend (FastAPI Web Service) is hosted on Render, handling heavy geospatial processing. The frontend (Vue.js) is seamlessly deployed on Vercel to leverage Edge network performance.
  
* **Iteration Archiving**: The exact codebase delivered at the end of each academic sprint is locked using a Git tag (e.g., `tag: iteration-2`). This specific branch is mapped to a preserved, iteration-specific URL, while the `main` branch continues to deploy to the live production URL.

* **Access Control (Stakeholder Protection)**: To protect academic integrity during development, pre-release iteration deployments are secured via **Vercel Edge Middleware**. This ensures a true HTTP Basic Auth layer intercepts unauthorized visitors before any client code is loaded, keeping work entirely private.
